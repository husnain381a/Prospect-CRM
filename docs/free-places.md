# Free places mode removed

The OpenStreetMap/Overpass/Photon option has been removed at the user's request. Discovery now uses official Google Places API (New). Previous queued open-source searches are cancelled; they are never converted to paid Google searches automatically.

Use [Google Places setup](google-places.md). Email remains enabled as a workflow; WhatsApp and calling remain implemented and paused for later activation. Existing historical source records and migration history are preserved.
