# Provider documentation reviewed

Reviewed on **22 October 2026**. Recheck before enabling a provider; terms and APIs can change.

- [Google Places policies](https://developers.google.com/maps/documentation/places/web-service/policies): storage/caching restrictions, place-ID exception, attribution and regional terms. Discovery now checks the server API key without the former custom CRM-license-reference gate. Separate export and voice-use flags remain default off; source attribution is preserved.
- [Supabase SSR](https://supabase.com/docs/guides/auth/server-side) and [Next.js quickstart](https://supabase.com/docs/guides/getting-started/quickstarts/nextjs): cookie-backed browser/server clients, authoritative user checks, credentials and RLS. Every protected request verifies `auth.getUser()` and workspace membership; database access also enforces RLS or narrowly authorized security-definer functions.
- [Next.js App Router installation](https://nextjs.org/docs/app/getting-started/installation) and the installed Next.js 16.4.2 route/server-client documentation: App Router, React client interactions and server route handlers. The installed version's `AGENTS.md` references bundled docs.
- [Resend idempotency](https://resend.com/changelog/idempotency-keys) and [webhook verification](https://resend.com/docs/webhooks/verify-webhooks-requests): stable send keys and signature verification against the original request body. The transport preserves exact approved text and uses Svix to verify callbacks. Uncertain outcomes are held for reconciliation rather than retried automatically.
- [WhatsApp Business Messaging Policy](https://whatsappbusiness.com/policy/): recipient opt-in, approved templates for initiation, opt-outs and the service window. The displayed policy was updated 23 September 2026. Meta's Cloud API/reference pages returned HTTP 429 during this review. The official Meta ecommerce sample source was reviewed for template payload and template-list APIs. The adapter now participates in the approved worker pipeline with live template checks, verified webhooks and opt-in gating. Account/version behavior still requires real activation tests.
- [Twilio Call resource](https://www.twilio.com/docs/voice/api/call-resource): configurable official API adapter. Automated calls now use separate version-bound approval, consent review, verified status/instruction callbacks and press-9 suppression. Account-specific integration tests remain required. A `tel:` link records only click initiation, not a completed call or a verified status.

No jurisdiction-specific automated legal interpretation is shipped. The platform requires a recorded permission/evidence/jurisdiction review and blocks unresolved eligibility.

- [Google Maps Platform terms](https://cloud.google.com/maps-platform/terms) and [Text Search New](https://developers.google.com/maps/documentation/places/web-service/text-search): reviewed storage/no-scraping/text-to-speech restrictions, response fields, field masks and pagination. Search coverage and costs are estimates, not exhaustive coverage or billing guarantees.
- [Meta template example source](https://github.com/fbsamples/whatsapp-api-examples/blob/main/template-for-ecommerce-js/messageHelper.js): official text-template parameter payload and business-account template-list endpoint.
- [Twilio security](https://www.twilio.com/docs/usage/security), [SDK webhook tests](https://github.com/twilio/twilio-node/blob/main/spec/unit/webhooks/webhooks.spec.js) and [Gather](https://www.twilio.com/docs/voice/twiml/gather): canonical public URL plus sorted form parameter HMAC verification, account matching, bounded voice instructions and keypad opt-out. The local implementation checks every received form field.

- Free-source evaluation: [Overpass source](https://github.com/drolbr/Overpass-API), [Photon source](https://github.com/komoot/photon), [Pelias source](https://github.com/pelias/pelias) and [gosom scraper](https://github.com/gosom/google-maps-scraper). This evaluation is historical: Overpass/Photon have now been removed at the user's request; a scraper's software license is not an official free Google dataset/API license.
- [Private.coffee Overpass terms](https://overpass.private.coffee/) reviewed for public commercial access, responsible request behavior and lack of availability warranty. [OpenStreetMap copyright](https://www.openstreetmap.org/copyright) reviewed for ODbL attribution/distribution requirements. Those public endpoints are no longer used. See [official Google setup](google-places.md).
